# K6 Performance Analytics

This directory contains tools for analyzing and visualizing k6 performance test results.

## Directory Structure

```
performance-analytics/
├── data/                    # k6 CSV output files (auto-generated)
│   ├── rest/               # REST API test results
│   └── graphql/            # GraphQL API test results
├── output/                  # Generated charts (auto-generated)
│   ├── rest/               # REST API charts
│   └── graphql/            # GraphQL API charts
├── summary/                 # k6 test summaries (auto-generated)
│   ├── rest/               # REST API summaries
│   └── graphql/            # GraphQL API summaries
├── k6_chart_generator.py    # Main chart generation script
├── requirements.txt         # Python dependencies
└── README.md               # This file
```

## Setup

1. Install Python dependencies:
```bash
pip install -r requirements.txt
```

## Usage

### Step 1: Generate k6 Test Results

#### For REST API Tests:
```bash
# From repository root
cd backend-rest
k6 run --out csv=../performance-analytics/data/rest/1_get_project_info.csv tests/k6/test_1_get_project_info.js
```

#### For GraphQL API Tests:
```bash
# From repository root
cd backend-graphql
k6 run --out csv=../performance-analytics/data/graphql/1_get_project_info.csv tests/k6/test_1_get_project_info.js
```

### Step 2: Generate Performance Charts

```bash
# From performance-analytics directory
cd performance-analytics
python k6_chart_generator.py
```

### Generated Files

After running k6 tests, you'll have:

1. **CSV Data Files** (in `data/rest/` and `data/graphql/`):
   - Raw performance metrics with stage tags
   - Used by the chart generator

2. **Summary Files** (in `summary/rest/` and `summary/graphql/`):
   - JSON files with test statistics
   - Average response times, error rates, throughput, etc.

3. **Chart Files** (in `output/rest/` and `output/graphql/`):
   - PNG charts showing response times by stage
   - Generated by running the chart generator

### Advanced Usage

#### Process a specific file:
```bash
python k6_chart_generator.py --file data/rest/1_get_project_info.csv
```

#### Custom directories:
```bash
# Use custom data and output directories
python k6_chart_generator.py --data-dir /path/to/csv/files --output-dir /path/to/output
```

## Chart Types

### Response Time Chart
- Shows HTTP response times over time with stage information
- Automatically detects load test stages based on timestamp gaps
- Color-codes different stages for easy identification
- Includes stage transition lines and statistics
- Shows stage-specific performance metrics
- Automatically routes to appropriate output directory based on API type

## CSV File Format

The script expects k6 CSV output files with the following structure:
- `metric_name`: Type of metric (e.g., 'http_req_duration', 'http_reqs', 'http_req_failed')
- `timestamp`: Unix timestamp
- `metric_value`: The metric value
- Additional columns are ignored for charting

## Output

Generated charts are automatically saved to the appropriate subdirectory based on API type:
- REST API charts → `output/rest/{filename}_response_time.png`
- GraphQL API charts → `output/graphql/{filename}_response_time.png`

The script automatically detects the API type based on:
1. File path (if in `data/rest/` or `data/graphql/` subdirectories)
2. Filename (if contains 'rest', 'graphql', or 'graph')
3. Defaults to REST if cannot determine

## Stage Detection

The script uses stage tags from k6 test execution to identify different load test phases:
- **Stage tags**: k6 tests automatically add `stage`, `stage_name`, and `api_type` tags to each request
- **Stage numbering**: Stages are numbered based on k6 test configuration (Stage 1, Stage 2, etc.)
- **Stage statistics**: Each stage shows average response time, request count, and duration
- **Visual indicators**: Stage transitions are marked with red vertical lines on charts
- **Color coding**: Each stage is plotted in a different color for easy identification

## Features

- **Automatic timestamp conversion**: Converts Unix timestamps to readable datetime format
- **Response time charts only**: Focused on the most important performance metric
- **Automatic stage detection**: Uses stage tags from k6 test execution
- **Stage visualization**: Color-coded stages with transition lines and statistics
- **Automatic API type detection**: Routes REST and GraphQL results to appropriate directories
- **Batch processing**: Process multiple CSV files at once from all subdirectories
- **High-quality output**: 300 DPI PNG files suitable for reports
- **Statistical overlays**: Mean, max, min lines on response time charts
- **Stage analysis**: Detailed stage-by-stage performance breakdown
- **Flexible input**: Works with any k6 CSV output format

## Troubleshooting

### Common Issues

1. **No CSV files found**: Ensure your CSV files are in the `data/` directory
2. **Import errors**: Run `pip install -r requirements.txt` to install dependencies
3. **Empty charts**: Check that your CSV files contain the expected metric names
4. **Memory issues**: For very large CSV files, consider processing them individually

### Performance Tips

- For large CSV files (>100k rows), processing may take a few minutes
- Charts are automatically optimized for readability
- Output files are compressed PNG format for efficient storage
